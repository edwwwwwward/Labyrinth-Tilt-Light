# Labyrinth-Tilt-Light
Game puzzle labirin 2D Kotlin Jetpack Compose (MVVM &amp; SQLite).  Fitur &amp; Sensor:  Accelerometer: Gerak bola sesuai kemiringan HP.  Light Sensor: Peta terang jika cahaya >50 Lux, gelap (fog of war) jika ≤50 Lux.  SQLite: Rekor waktu tercepat.  Cara Jalan: Buka di Android Studio, Sync Gradle, klik Run.
